Feature For the Security Command Center Standard tier, AI Protection is supported for both projects and organizations. Project-level activations for the Standard tier include access to the AI security dashboard , basic inventory view (excluding Gemini models), and baseline security findings. Some features of AI Protection are only available for the Premium and Enterprise tiers or for organization-level activations.
